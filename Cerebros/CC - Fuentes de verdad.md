# CC - Fuentes de verdad

[[CC - Proyecto y equipo]] · [[ChapterCore - Cerebro central]]

> [!abstract] Cómo resolver discrepancias entre documentos, código y mockups.

1. Decisiones confirmadas en `CONTEXTO.md` y requisitos escritos posteriores → objetivo del producto.
2. El código implementado → comportamiento actual (no reemplazarlo solo por un mockup).
3. Mockups → guían diseño y flujos, sin autorizar funciones fuera del MVP.
4. Las carpetas de herramientas no prueban que algo exista.
5. Si dos requisitos chocan, detenerse y preguntar.
