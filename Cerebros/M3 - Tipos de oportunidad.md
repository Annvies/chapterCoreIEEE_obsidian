# M3 - Tipos de oportunidad

[[M3 - Descubrimiento]] · [[Cerebro 3 - Oportunidades IEEE]]

> [!abstract] Qué es
> La base de datos solo admite tres tipos: `beca`, `concurso` y `voluntariado`.

> [!info] Confirmado en el código
> - Los grants, travel grants, fellowships y premios con dotación se clasifican como **beca**.
> - No existe un tipo «premio» ni «grant» separado.
