# CC - Decisiones confirmadas

[[CC - Proyecto y equipo]] · [[ChapterCore - Cerebro central]]

> [!abstract] Decisiones del equipo fechadas el 2026-10-19.

| Tema | Decisión |
|---|---|
| Stack | NestJS + TypeORM + PostgreSQL; React; npm |
| Producción | Neon + Vercel (backend y frontend separados); CI/CD con GitHub Actions |
| Desarrollo | PostgreSQL 18 en Docker, base única `chaptercore_dev` |
| Autenticación | Propia (bcrypt + JWT), sin IdP ni "IEEE Account"; alta por invitación |
| Permisos | Matriz del mockup 03 como oficial; cuatro niveles |
| Contactos | Visibilidad solo por matriz; capítulo como dato y filtro; CSV todo o nada |
| Oportunidades | Solo fuentes oficiales IEEE; Gemini nivel gratuito; revisión humana antes de publicar |
| Difusión | Acortador de URLs con QR dinámicos |
| KPIs | Fórmulas de satisfacción y NPS; periodos mes, semestre y gestión |
